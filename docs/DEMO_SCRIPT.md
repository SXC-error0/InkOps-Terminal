# InkOps Terminal — 演示脚本 V1.0

## 视频标题候选

- 《我把墨水屏做成了 AI 独立开发者作战终端》
- 《服务器挂了以后，我桌上的电子纸自动变成警报牌》
- 《我做了一块会判断此刻最重要事情的墨水屏》

## 演示场景 (约 90 秒)

### 场景 1: 晨间启动 (0:00–0:15)

- 打开上位机，Bridge 页面显示系统状态
- 设备在线，"AI 导演活跃"
- 事件流显示启动事件

### 场景 2: 任务铸造 (0:15–0:35)

- 切换到 Quest 频道
- 输入今日待办："完成自动刷新接口，修复二维码入口，去健身房"
- 点击「生成任务卷轴」
- AI 输出 RPG 任务卡：主线/Boss/弱点/禁令/奖励
- 墨水屏预览区域显示生成的 400×300 图片
- 点击「推送到墨水屏」

### 场景 3: 发射台 (0:35–0:50)

- 切换到 Launch 频道
- 输入项目名 "InkOps Terminal"
- AI 生成上线路程简报
- 显示：进度条、倒计时 T-14d、阻塞项、今日唯一指令

### 场景 4: 守夜人告警 (0:50–1:10)

- 切换到 Watcher 频道
- 添加监控目标 (演示用不可达 URL)
- 触发健康检测
- 检测失败后自动生成 SYSTEM_ALERT 页面
- Bridge 事件流显示告警事件
- Director 自动推荐显示告警页 (P0)

### 场景 5: 信号箱留言 (1:10–1:25)

- 切换到 Signals 频道
- 生成留言二维码
- 提交一条测试留言
- 安全过滤通过后自动生成 POSTCARD 明信片
- 在 Bridge 预览区域可见

### 场景 6: 战报结算 (1:25–1:35)

- 切换到 Studio 频道
- 展示今日生成的所有页面历史
- 每条记录显示模板类型、状态、时间

## 录制准备清单

- [ ] 上位机运行 (Vite dev server + Python backend)
- [ ] 墨水屏设备连接并可见
- [ ] 至少 3 条真实的待办事项
- [ ] 至少 1 个可监控的 URL (建议用本地)
- [ ] 至少 1 条测试留言
- [ ] 屏幕录制工具 (OBS / QuickTime)
- [ ] 确保没有敏感信息 (API Key、私人数据) 出现在画面中

## 产品叙事话术

> 每个独立开发者都在和信息过载作战。任务列表、GitHub 通知、服务器告警、用户留言...所有这些都挤在屏幕的角落里。
>
> InkOps Terminal 做了一件事：在现实桌面上放一块墨水屏，AI 帮你挑出当前最值得看的一页。
>
> 任务变成副本。提交变成战绩。异常变成警报。留言变成纸面信号。发布变成头版。
>
> 这不是仪表盘，这是指挥终端。
