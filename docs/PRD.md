# InkOps Terminal — 产品需求文档 (PRD) V1.0

## 产品定位

**一台由 AI 驱动、通过 4.2 寸电子墨水屏展示关键信息的独立开发者桌面作战终端。**

它不是被动更新图片的显示屏，而是将任务、开发进度、服务告警和访客留言，通过 AI 压缩编排后，推送到实体墨水屏的指挥中心。

## 核心场景

| 场景 | 用户行为 | 屏幕呈现 |
|------|----------|----------|
| 早晨启动 | 输入今日待办 | RPG 任务卷轴 |
| 开发中 | 提交代码 | 终端显示今日战绩 |
| 服务异常 | 被监控网站宕机 | 自动弹出告警页面 |
| 社交互动 | 朋友扫码留言 | 纸感明信片上屏 |
| 夜间结算 | AI 汇总当日事件 | 发布战报头版 |

## 用户画像

- 独立开发者 (Indie Maker)
- 有桌面工位、长时间在电脑前工作
- 需要在现实空间中有可见的目标和状态提示
- 作品有对外展示和传播需求

## 核心机制: AI Display Director

多个模块同时产生候选页面（任务、告警、留言、战报），但实体屏幕只能显示一页。

**AI Display Director** 根据事件优先级选择当前最值得显示的页面：

| 级别 | 事件类型 | 行为 |
|------|----------|------|
| P0 | 紧急异常（网站/API/设备离线） | 立即覆盖 |
| P1 | 关键成果（发布、首个里程碑） | 立即展示 |
| P2 | 日常核心（早间任务、晚间结算） | 定时展示 |
| P3 | 社交互动（新留言） | 空闲展示 |
| P4 | 轻内容（知识卡、宠物页） | 不打扰 |
| P5 | 待机页面 | 常驻 |

## MVP 功能范围

| 模块 | 功能 |
|------|------|
| Command Bridge | 总指挥舱、屏幕预览、AI 推荐、事件流 |
| AI Daily Quest | 输入待办 → AI 生成 RPG 任务卷轴 |
| Launch Control | 项目进度、阻塞项、AI 今日指令 |
| Terminal Status | GitHub 提交、服务状态、MVP 进度 |
| System Watcher | HTTP 健康检测、自动告警页面 |
| Signal Box | 留言二维码、明信片生成、安全过滤 |

## 非功能需求

- 所有 API Key 不进仓库
- 图片在 Python 端渲染为 400×300 黑白 PNG
- AI 输出必须经 Pydantic Schema 校验
- 留言默认人工确认后推送
- 不实时轮播, 仅在值得注意时刷新

## 技术边界

- ESP8266 不运行 AI
- 不展示实时 K 线、不做自动交易
- 不让 AI 自由排版，固定模板渲染
- 首版本不做云同步

## 成功标准

1. 可生成至少 6 种统一风格的 400×300 墨水页面
2. AI 能将任务、进度、异常、留言转换为结构化字段
3. 页面能稳定刷新到真实墨水屏
4. 异常能触发告警页面
5. 留言可生成明信片页面
6. 可录制完整演示视频
7. 仓库不含任何 API Key 或私人数据
